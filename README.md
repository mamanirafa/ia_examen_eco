# NEXO · Examen integrador de IA

Examen web de 75 minutos para 5.º A, Ciclo Orientado en Economía (Colegio Integral de Educación Ushuaia). Integra lo trabajado en Bóveda Neural, PromptLab y Mi Tutor IA: concepto de IA, prompting, Big Data e IA, Internet de las cosas, transmedia y prosumidores, y redes PAN, LAN, MAN y WAN.

- A cada estudiante le toca un sorteo propio de 41 desafíos de un banco de 126, en otro orden y con las opciones mezcladas.
- Incluye opción múltiple, V/F, selección múltiple, arrastrar y soltar, unir, ordenar, completar la frase, detectar alucinaciones, escribir un prompt a partir de una imagen o un texto, justificar respuestas, elegir el prompt que generó un resultado y un desafío final con IA real.
- Sala de espera con inicio sincronizado: el docente habilita el comienzo para todos desde `panel.html` y sigue el avance del curso en vivo.
- Muestra el progreso, la nota parcial y las insignias después de cada respuesta.
- Con nota 6 o más se emite el certificado EsencIA y un anexo con las insignias. Con menos de 6, se entrega la constancia de finalización del trayecto con las insignias logradas.
- Cada respuesta e incidente se registra en Google Sheets (ver `apps_script/Codigo.gs`).
- Idioma: español.
